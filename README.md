# 청년상인 로우데이터 취합 자동화

담당자가 매달 원본 자료를 업로드하면 **전월 최종본 + 이번 달 발행리스트 + 채널 원본 데이터**를
합쳐 이번 달 로우데이터(취합) 엑셀을 완성하고, 전월 월간보고서 PPT를 함께 올리면 이번 달
PPT까지 만들어주는 Streamlit 웹앱입니다.

청년상인은 인스타그램(+블로그) 채널만 운영해서 LX세미콘 자동화보다 단순한 단일 흐름으로
구성했습니다(로우데이터 취합만 하며, AD 데이터도 같은 파일 안에 함께 채워집니다).

## 핵심 원칙

- **추측 금지** — 원본에 없거나 매칭이 애매한 값은 셀에 `확인 필요`를 직접 씁니다.
- **발행리스트 기준** — 발행리스트의 이번 달 발행건은 빠짐없이 행을 추가합니다.
- **전월 구조 복제** — 전월 최종본의 서식을 그대로 복제해 맨 아래에 이번 달 블록만 덧붙입니다.
- **기존 수식 보존** — 전월 최종본에 있던 수식(합계/평균/누적/증감률 등)은 절대 값으로
  덮어쓰지 않습니다. 이번 달에 새로 채우는 집계 셀도 전월과 같은 수식 패턴(SUM/AVERAGE/
  COUNTIF/SUMIF 등, 범위만 이번 달 위치로 조정)으로 써서 파일을 열면 전월 행과 새 행이
  서식·수식 모두 동일하게 보이고, 엑셀이 열릴 때마다 살아있는 값으로 재계산됩니다.

## 화면 구성

앱은 **로우데이터**와 **월간보고서 PPT** 두 패널로 나뉘며, 서로 독립적으로 실행할 수
있습니다. PPT 패널은 로우데이터 패널이 만든 결과물을 자동으로 이어받지 않고 별도로
업로드받습니다 — 로우데이터를 만든 뒤 팔로워 수·블로그 성과처럼 `확인 필요`로 남은 값을
엑셀에서 직접 채우고, 그 파일을 다시 올려서 PPT를 만드는 흐름이기 때문입니다.

```
[로우데이터]                                    [월간보고서 PPT]
1 입력 파일                                      최종 로우데이터 입력
  [전월 최종본: 로우데이터 xlsx / 월간보고서 ppt]    [최종 로우데이터(취합) 엑셀] ★
  [이번 달 콘텐츠 발행리스트] ★
                                                 기타 데이터입력
2 채널 원본 데이터                                 [인스타그램 팔로워 비중 CSV]  [제휴 오픈보고서]
  [인스타그램 콘텐츠 원본] ★ [인스타그램 AD 원본] ★

[로우데이터 만들기]                               [PPT 만들기]
 → 로우데이터(취합) 엑셀 다운로드                    → 월간보고서 PPT + (제휴/팔로워 반영 시)
                                                    업데이트된 로우데이터 다운로드
```

전월 월간보고서 PPT는 왼쪽 '전월 최종본' 카드에 올리고, 오른쪽 'PPT 만들기'가 그 파일을
템플릿으로 재사용합니다.

## 매칭 규칙

### 콘텐츠 ↔ 성과 원본
고유 링크(URL)로 매칭합니다. 인스타그램은 `/p/`와 `/reel/` 경로가 같은 게시물을 가리킬 수
있어 경로 종류를 무시하고 shortcode만 비교합니다.

### 콘텐츠 ↔ 광고
광고 소재명(`YYMMDD_제목`)의 날짜 코드는 **광고를 만든 날짜**이며 콘텐츠 발행일보다
1~2일 늦게 생성되는 경우가 흔합니다(실데이터로 확인됨: 같은 날 발행된 콘텐츠 2건에 대해
서로 다른 날 광고를 만든 사례). 그래서 날짜 근접도(±3일)와 제목 텍스트 유사도를 함께
점수화해서 매칭하고, 애매하면 `확인 필요`로 남깁니다.

- **광고비**(콘텐츠 시트) = 매칭된 광고의 실지출을 만원 단위로 올림
- **광고도달**(콘텐츠 시트) = 매칭된 광고의 '도달' 값 그대로
- **광고예산**(AD 데이터/AD 데이터(전체) 시트) = 원본에 캠페인별 예산 데이터가 없어,
  실지출을 만원 단위로 올린 값을 그대로 씁니다(예: 49,415 → 50,000, 98,879 → 100,000).
  AD 데이터(전체)의 '광고비(총합)'과 운영요약의 '연간 광고비 지출 현황'은 이 예산 값을
  SUMIF로 집계하는 살아있는 수식이라, 예산 값이 채워지면서 자동으로 맞는 합계가 됩니다.
- AD 데이터 시트 자체의 '지출 금액'은 원본 그대로(raw)를 쓰고, 만원 올림은 '광고예산'과
  콘텐츠 시트의 '광고비'에만 적용합니다(전월 최종본의 기존 규칙을 그대로 따름).
- '평균 도달당 비용'은 전월 최종본의 기존 수식 관례(`(지출÷결과)×1000`)를 그대로 따릅니다.
- 인스타그램/블로그 시트의 '유형' 열은 텍스트라 평균/합계 대상에서 뺍니다(전월 최종본도
  이 열은 비어 있음).

## 자동으로 채우지 못하는 항목(확인 필요로 남김)

- 블로그 콘텐츠의 조회/공감/댓글 — 이번 버전 입력에 블로그 성과 원본이 없음
- AD 데이터의 '타깃' — 원본에 없는 수기 항목
- AD 데이터의 '시작'/'종료' — 광고 원본에 개별 광고 단위 날짜가 없는 경우
- 채널 팔로워 시트 — 팔로워 일별 데이터 파일이 없어 이번 버전에서는 건드리지 않음(수기 유지)

## PPT 자동 채움

전월 월간보고서 PPT를 업로드하면(선택), 같은 실행에서 만든 로우데이터를 바탕으로 이번 달
PPT도 함께 만듭니다. 슬라이드 순서가 아니라 **표 헤더 내용**으로 표 종류를 인식하므로
슬라이드가 재배치돼도 동작합니다.

**자동으로 채우는 표/차트**
- KPI 달성 현황 표(월별 발행수/도달수/조회수/참여수 + 누적/목표/달성률) + 그 옆 달성/잔여
  도넛 차트 4개 + 도넛 아래 퍼센트 텍스트 + '누적 실적 OOO' 텍스트(표와 같은 값으로 동기화,
  색상·서식은 원래 런의 서식을 유지한 채 숫자만 교체)
- 전월 데이터 비교 표(인스타그램·블로그를 한 표에 나란히, 전월/당월/전월 대비 증감률)
- 채널(인스타그램/블로그) 단독 '팔로워 수'·'이웃수' 비교 표(전월/당월/증감률)
- 콘텐츠 발행 내역 표(제목에 발행 URL 하이퍼링크 포함, 이번 달 건수에 맞춰 행 자동 증감)
- 광고 진행 개요·참여/도달/동영상조회 캠페인별 내역 표, 예산 현황 표
- 월간 팔로워 수 추이 차트(최근 3개월)·일간 팔로워 수 차트(값이 있는 날짜만, 가장 최근
  네이티브 차트를 `chart.replace_data()`로 갱신 — '채널 팔로워' 시트의 수기 입력값을 그대로 반영)
- 인스타그램 팔로워 성별/연령 비중 차트(파이+막대, 데이터 레이블/축을 `0.0%` 퍼센트
  서식으로 강제 지정해 `0.492`가 아니라 `49.2%`로 표시되도록 함)
- 우수 콘텐츠 TOP3(도달수 기준/반응수 기준 — 반응수 기준은 제목에 '이벤트'가 들어간
  콘텐츠를 순위 대상에서 제외): 주제·도달·조회·반응·유형·광고비(또는 좋아요/댓글/공유/저장)를
  채우고, 템플릿에 남아있던 스크린샷 이미지는 삭제하며, 소제목의 월 표기를 이번 달로 변경
- 인플루언서 제휴 표(인스타/블로그 각각): 시장·오픈일·아이디(블로거)·내용요약(또는 제목)·
  URL 하이퍼링크·팔로워/조회/좋아요/댓글 등 + 합계 행, 인원 수에 맞춰 행을 늘리거나 줄이고
  '- 총 N인' 라벨도 실제 인원수로 갱신

**팔로워 성별/연령 차트도 자동 채움** — 인스타그램 팔로워 비중 CSV를 올리면 로우데이터에
'인스타그램 팔로워 타깃' 시트가 새로 생기고(성별 비중, 연령대별 성별 비중을 일반 셀 값으로
저장 — 수식이 아니라 언제든 손으로 고칠 수 있음), PPT의 성별 파이차트·연령대별 성별
막대차트가 `chart.replace_data()`로 갱신됩니다. 차트의 카테고리 라벨(연령 구간 표기 등)은
PPT 템플릿에 있던 것을 그대로 쓰고 값만 CSV 기준으로 바꿉니다. 이 방식은 PPT 내장 차트의
편집용 데이터도 함께 갱신되므로, PPT를 열어 차트의 '데이터 편집'을 눌러도 정상적으로
동작합니다.

**'채널 팔로워' 시트 기반 자동 채움** — 팔로워/이웃수는 채널 자체에서 내려받을 수 있는
원본이 없어 담당자가 '최종 로우데이터'의 '채널 팔로워' 시트(월별 요약표 + 일별 수기 입력표)에
직접 채워 넣습니다. PPT 만들기 단계에서 이 시트를 읽어 KPI 옆 '전월 데이터 비교 표', 채널별
단독 비교 표, 월간/일간 팔로워 추이 차트를 채웁니다. 블로그 쪽 '팔로워수(이웃수)'·'콘텐츠
총 도달수(조회수)' 행은 이웃수 자체가 거의 변하지 않아 일별 조회수/방문횟수 합계로
대체 산출하는데, 의도한 지표가 맞는지는 확인 필요로 표시됩니다.

**자동 채움 대상이 아님** (스크린샷·서술형이라 전월 내용이 그대로 남아있으니 직접 교체)
운영 캘린더, 검색 상위 노출 현황, 이벤트 소개 슬라이드. 우수 콘텐츠 TOP3의 표는 자동으로
채우지만 그 안의 스크린샷 이미지는 직접 넣어야 합니다.

## 제휴 데이터 / 팔로워 비중 데이터

인플루언서 체험단 콘텐츠는 청년상인 자체 채널 콘텐츠가 아니라 외부 계정 게시물이라
'인스타그램'/'블로그' 시트에는 섞지 않고, 별도 **'제휴'** 시트를 새로 만들어 이번 달
집행 내역을 이어붙입니다. 이 데이터와 '인스타그램 팔로워 타깃' 시트는 전월 최종본에
존재하지 않던 신규 시트라 '기존 수식 보존' 원칙이 적용되지 않으며(보존할 기존 수식이
없음), **월간보고서 PPT 패널에서** '최종 로우데이터'에 반영한 뒤 그 자리에서 함께
다운로드할 수 있습니다.

## 실행

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## 검증 현황

### 검증 중 잡은 버그(참고용)

- 전월 최종본의 여러 셀이 `=SUM(...)` 같은 수식이라 openpyxl로는 계산값을 못 읽음 →
  같은 파일을 `data_only=True`로 한 번 더 읽어 캐시된 계산값을 보조로 사용하도록 수정.

  있어, 날짜만으로 매칭하면 같은 날 발행된 다른 콘텐츠에 잘못 매칭됨 → 날짜 근접도와
  제목 유사도(최장 공통 부분문자열 비율)를 함께 점수화하도록 수정.
- PPT의 동영상조회 캠페인 표는 '노출'/'도달' 컬럼도 가지고 있어 도달 표 인식 조건과

  계산한 값으로 덮어쓰고 있었음** → 전체를 다시 설계해서, 이번 달에 채우는 집계 셀도
  전월과 같은 수식 패턴(범위만 이번 달 위치로 조정)으로 쓰도록 변경. PPT처럼 실제 숫자가
  필요한 곳은 셀을 다시 읽지 않고 계산 과정에서 이미 만든 파이썬 값을 그대로 전달.
